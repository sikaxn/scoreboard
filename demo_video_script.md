# Smart Scoreboard Demo Video Script

Target length: about 3 minutes

Style: simple launch-demo pacing. The viewer should understand the app even if they only know how to use an iPad or computer. Use short sentences. Show one clear action at a time. Avoid developer words unless the app screen itself shows that label.

Main idea: one person uses the app to control the game, while everyone else sees a clean scoreboard on a TV, projector, Apple TV, iPad, or Mac.

## Video Structure

- 0:00-0:15: the app promise. This part must work as a complete short video.
- 0:15-1:00: the basic steps. This part must work as a complete one-minute demo.
- 1:00-3:00: deeper features for teams, events, livestreams, and repeat use.

## Recording Setup

- Show the iPad or Mac app screen.
- Also show a TV, projector, Apple TV, iPad, or Mac screen with the big scoreboard.
- Best opening shot: app controls on one side, big scoreboard on the other side.
- Use Basketball first. It shows points, game clock, period, shot clock, and possession quickly.
- Use real-looking names, such as "North" and "South", instead of sample text.

## Scene 1 - Start With The Result

Time: 0:00-0:15

Show on video:

- Start with the big scoreboard on a TV or projector.
- Show the app screen beside it.
- Tap a score button.
- Start the game clock.
- Change possession.
- Show the big scoreboard updating after each tap.

Narration:

> This is Smart Scoreboard. Use your iPad or Mac to run the game. The TV shows the scoreboard. Tap the score, start the clock, and the big screen updates right away.

On-screen text:

Run the game on your device.

Show the scoreboard on the big screen.

15-second ending:

- End on the score and clock changing on both screens.
- Fade out after the line: "The big screen updates right away."

## Scene 2 - Choose The Game

Time: 0:15-0:30

Show on video:

- Open Settings.
- Open Game Setup.
- Tap Basketball.
- Type the event name.
- Type the two team names.
- Show the starting period, game clock, and shot clock.
- Tap Go to Control Board.

Narration:

> To begin, choose the game type. Add the event name. Add the two teams. Check the starting clock. Then go to the control board.

On-screen text:

Choose a game.

Add teams.

Go to Control Board.

## Scene 3 - Run The Game

Time: 0:30-0:45

Show on video:

- Add 2 points for one team.
- Add 3 points for the other team.
- Start and pause the game clock.
- Reset the shot clock.
- Change possession.
- Move to the next period.
- Show the big scoreboard after each action.

Narration:

> The control board gives you the buttons you need during the game. Score points. Start or pause the clock. Reset the shot clock. Change possession. Move to the next period.

On-screen text:

Score.

Clock.

Shot clock.

Period.

## Scene 4 - Choose What The Audience Sees

Time: 0:45-1:00

Show on video:

- Tap Display Control.
- Show the preview of the big scoreboard.
- Tap Scoreboard.
- Tap Player View.
- Tap Team View.
- Tap Event Logo.
- Tap Black Screen.
- Return to the game controls.

Narration:

> You also choose what people see on the big screen. Show the full scoreboard, a team view, a player view, an event logo, or a black screen. Only the person running the game sees the buttons.

On-screen text:

Choose the big-screen view.

Only you see the buttons.

60-second ending:

- End on the full scoreboard view.
- Fade out after the line: "Only the person running the game sees the buttons."

## Scene 5 - Players And Team Details

Time: 1:00-1:25

Show on video:

- Open Settings.
- Open Players.
- Show both team rosters.
- Add or edit one player name.
- Show active lineup controls.
- Return to the live control board.
- Open Players from the live board.
- Add a foul or card to one player.
- Show the player detail on the big scoreboard.

Narration:

> For games with player tracking, add the roster before the game. During the game, manage the active lineup, fouls, cards, and substitutions without leaving the scoreboard.

On-screen text:

Rosters.

Lineups.

Fouls and cards.

Substitutions.

## Scene 6 - More Than One Sport

Time: 1:25-1:50

Show on video:

- Open Game Setup.
- Quickly show the game choices: Simple, Basketball, Volleyball, Soccer, Hockey, Chess, Debate, and Custom.
- Show Soccer player cards.
- Show Hockey penalty timers.
- Show Chess side clocks.
- Show Debate speech segments and prep time.
- Show Custom Sport with switches for score, clock, period, shot clock, possession, players, and team counters.

Narration:

> Smart Scoreboard supports many kinds of events. Use a ready-made setup for common sports, chess, and debate. Or create a custom game by turning on only the parts you need.

On-screen text:

Sports.

Chess.

Debate.

Custom games.

## Scene 7 - Show The Scoreboard On Other Devices

Time: 1:50-2:15

Show on video:

- Open Settings.
- Open Integration.
- Open Remote Display.
- Turn on Operator Broadcast, the switch that sends the scoreboard to other screens.
- Show a second device waiting in Remote Display mode.
- Show the four-digit pairing code.
- Pair the second screen.
- Change the score on the main device.
- Show the second device updating.

Narration:

> You can also send the scoreboard to another Apple device nearby. Pair an Apple TV, iPad, or Mac. The main device runs the game. The other device shows the scoreboard.

On-screen text:

Pair another screen.

One device controls the game.

Other devices show the score.

## Scene 8 - Optional Livestream Tools

Time: 2:15-2:35

Show on video:

- Stay in Integration.
- Open the screen labeled Web API.
- Show the built-in demo scoreboard page.
- Show the small score graphic for livestreams.
- Open the screen labeled Bitfocus Companion.
- Show one game action set to press one Companion button.

Narration:

> For livestreams, Smart Scoreboard can share the live score with score graphics and video tools. It can also press a Companion button when a game action happens.

On-screen text:

For livestreams.

For score graphics.

For video controls.

Plain-language note for editing:

- Do not explain developer labels in the main narration.
- If the screen shows developer labels, keep the shot short and focus the narration on what the viewer gets: live score graphics and video controls.

## Scene 9 - Make The Display Match The Event

Time: 2:35-2:50

Show on video:

- Open Theme.
- Change the scoreboard theme.
- Open Display.
- Show team logos.
- Show event logo.
- Show clock alert colors.
- Show date and time on the big screen.
- Open Sound.
- Preview one sound.

Narration:

> Match the scoreboard to the room. Choose a theme. Add team logos. Add an event logo. Show clock warnings. Turn sounds on or off.

On-screen text:

Themes.

Logos.

Clock warnings.

Sounds.

## Scene 10 - Save Games And Review What Happened

Time: 2:50-3:05

Show on video:

- Open Library.
- Show saved game files.
- Show Import and Export.
- Show Backup and Restore.
- Open Logs.
- Show a game log with score, clock, period, and player actions.
- Show export options.
- End on the app controls and big scoreboard side by side.

Narration:

> Save game setups for next time. Export logs after the event. Back up the app when you need to move to another device. Smart Scoreboard keeps the game easy to run and easy to show.

On-screen text:

Save setups.

Export logs.

Back up the app.

Show on video:

Narration:

> Smart Scoreboard.

On-screen text:

Smart Scoreboard

## Recording Checklist

- Record the first 15 seconds until it is clean and easy to understand.
- Record the first 60 seconds as a complete short demo.
- Keep the big scoreboard visible whenever a button changes the game.
- Use simple team names and a realistic score.
- Avoid showing long settings lists for more than a few seconds.
- Do not narrate programming terms.
