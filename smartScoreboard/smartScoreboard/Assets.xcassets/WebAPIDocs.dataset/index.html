API Docs

EndpointUse
GET /api/v1/stateLatest raw scoreboard state JSON.
GET /api/v1/display/background-imageCurrent external display background image binary. Photo and Animated Logo modes use this same image asset.
GET /api/v1/display/event-logoCurrent event logo binary with alpha preserved. Use display.showsEventLogo to decide whether to show it.
GET /api/v1/teams/{home|guest}/logoCurrent team logo binary with alpha preserved. Use display.showsTeamLogos to decide whether to show it.
GET /api/v1/healthService status, fixed ports, and connected WebSocket client count.
WS /api/v1/wsReceives scoreboard.state messages when state changes. Fixed Interval mode coalesces to a maximum of 10 updates per second; Real-Time Push mode sends every state change. Send {"type":"get"} to request the latest state.
