API Docs

EndpointUse
GET /api/v2/status/apiWeb API service status only: API version, supported versions, ports, update mode, status, client count, and generated time.
GET /api/v2/status/appApp identity/status only: app name, version, build, API version marker, and generated time.
GET /api/v2/stateLightweight v2 manifest listing resource names, hrefs, revisions, and generated time.
GET /api/v2/state/{game|runtime|display|rules|teams|clocks|players|debate|audio}One v2 resource envelope: schemaVersion, resource, revision, generatedAt, and data. debate returns null when the selected sport is not Debate.
GET /api/v2/display/background-imageCurrent external display background image binary. v1 image paths remain valid aliases.
GET /api/v2/display/event-logoCurrent event logo binary with alpha preserved. v1 image paths remain valid aliases.
GET /api/v2/teams/{home|guest}/logoCurrent team logo binary with alpha preserved. v1 image paths remain valid aliases.
WS /api/v2/wsSend {"type":"subscribe","apiVersion":"v2"} after connecting. The server sends a v2 manifest and separate scoreboard.v2.resource messages, then pushes changed resources only.
GET /api/v1/stateBackward-compatible v1 full state payload.
GET /api/v1/healthBackward-compatible v1 service health payload.
WS /api/v1/wsBackward-compatible v1 WebSocket behavior. Existing clients receive scoreboard.state envelopes and can send {"type":"get"}.
